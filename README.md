# CampusEats Task Tracker

Repository for the CampusEats lab task tracker. The application and CI workflow live in the nested `campuseats-task-tracker` folder.

## Layout

| Path | What it is |
|------|------------|
| `campuseats-task-tracker/` | Project root (gitignore, CI, and the app) |
| `campuseats-task-tracker/.github/workflows/ci.yml` | GitHub Actions workflow that installs Node.js 18 and runs the API script |
| `campuseats-task-tracker/SE3090_Lecture04_Demo/` | LankaMart API demo (PostgreSQL, authentication, roles, and permissions) |

Setup and a walkthrough of the demo are in [campuseats-task-tracker/SE3090_Lecture04_Demo/README.md](campuseats-task-tracker/SE3090_Lecture04_Demo/README.md).

## Branches

Active work is on the `dev` branch.
